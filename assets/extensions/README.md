# uBlock Origin Lite for YouTube TV

Shipped zip: `ublock-origin-lite.chromium.zip` (uBOLite 2026.1124.1811).
Source release: https://github.com/uBlockOrigin/uBOL-home/releases/tag/2026.1124.1811
License: GPL-3.0 (inside the zip).

PiDeck extracts this into `~/.config/pideck/extensions/ublock-origin-lite` on first YouTube TV launch and loads it with Chromium `--load-extension`.
